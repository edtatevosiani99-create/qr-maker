# QR Studio

Ready-to-open Flutter application project for Android and iOS.

Features: URL, text, phone, Wi-Fi, contact/vCard, email, location, live preview, QR/background colors, size, L/M/Q/H error correction, PNG saving, sharing, Russian/English/German/Georgian, light/dark mode.

The archive includes Android and iOS platform folders and the app logo. You do not need to create or add platform folders or logo files manually.

On a computer with Flutter installed:
1. Open this folder in Android Studio or VS Code.
2. Run `flutter pub get`.
3. Android: `flutter build appbundle --release`
4. iOS: on macOS, `flutter build ipa --release`

Flutter generates only its normal machine-specific/generated build files automatically; these should not be manually copied between computers.
